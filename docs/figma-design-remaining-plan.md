      сумма, дата, название, автокатегория, место, комментарий и сохранение.
      По умолчанию открывается полная форма; нажатие на сумму открывает нижнюю
      панель с цифровой клавиатурой, нажатие на дату — панель с календарём.
- [x] Показать ошибки суммы: пустая, нулевая, отрицательная, буквенная.
- [x] Собрать **Expense Edit** и подтверждение удаления.
- [x] Собрать **Analytics / Donut** и **Analytics / Bars** на одинаковых данных.
- [x] Добавить периоды: текущий месяц, предыдущий месяц, год, всё время,
      произвольный диапазон; переход между соседними месяцами.
- [x] Добавить пустое состояние аналитики.
- [x] Собрать **Categories**: встроенные и пользовательские категории.
      Активные категории идут единым списком и различаются бейджами
      «Встроенная» / «Своя».
- [x] Собрать форму создания/редактирования категории: название, цвет/иконка.
      В MVP форма доступна только для пользовательских категорий.

      подходящую иконку, а первую букву названия использовать только как fallback.
- [x] Показать ошибки пустого и дублирующего названия.
- [x] Спроектировать архивирование категории с расходами без потери записей.
      Встроенные и пользовательские категории можно архивировать и
      восстанавливать на отдельном экране «Архив»; «Прочее» защищена.
- [x] Показать количество запомненных правил категоризации.

## P1 — связанные состояния

- [x] Собрать фильтры списка: период, несколько категорий, место.
- [x] Показать активные фильтры, быстрый сброс и пустой результат.

- [x] Добавить настройку темы: system / light / dark.

## Прототип и проверка

- [ ] Связать FAB → Quick Add → сохранённый расход в списке.
- [ ] Связать строку расхода → Edit → обновлённый список.
- [ ] Связать категорию аналитики → список с тем же периодом и категорией.
- [ ] Проверить все экраны в Light/Dark и на размере Android 360×800.
- [ ] Проверить safe areas, отсутствие clipping и минимальный tap target 48 dp.
- [ ] Убедиться, что компоненты используют variables и text styles без hardcoded-цветов.

## Критерий готовности

Дизайн готов к реализации, когда F-01, F-02, F-05 и F-06 имеют полный happy path
и негативные состояния, F-07 связан прототипом, а все экраны читаемы в Light/Dark.
